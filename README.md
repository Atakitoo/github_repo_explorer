# GitHub Repository Explorer

A small Python project that uses the GitHub REST API to search for a user's public repositories.

## Features

- Search for a GitHub user
- Display repository information
- Show repository description, URL, language and star count
- Save repository data as JSON
- Export selected repository data to CSV
- Handle repositories without descriptions
- Handle HTTP errors

## Technologies

- Python
- urllib
- JSON
- CSV
- GitHub REST API

## How to Run

Make sure Python is installed, then run:

```bash
python main.py
